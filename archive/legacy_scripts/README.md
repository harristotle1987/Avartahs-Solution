# Legacy Scratch and Patch Scripts Archive

This directory contains historical one-off patch, migration, and diagnostic scripts used during earlier development turns of Avartah Solutions.

These scripts are preserved for provenance, historical context, and audit tracking, but are not executed during normal application build, test, or runtime workflows.

Active test suites remain in the root directory:
- `test-job-audit-suite.ts`: Comprehensive Job Finder, relevance, and authorization regression suite.
- `test-auth-suite.ts`: End-to-end session verification, cookie handling, and role enforcement suite.
- `test-prospects-suite.ts`: Geospatial prospect extraction and contact validation suite.
